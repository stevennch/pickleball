# 🎾 ラケットサークル組み合わせくん

ピックルボール・テニス・バドミントンなどのラケットスポーツサークル向けの、ダブルス総当たり組み合わせ生成Webアプリです。

**👉 アプリを開く: https://stevennch.github.io/matchmaker/**

## 機能

- **共有リンク** — サークルのデータ（メンバー・設定・対戦表）を圧縮してURLに埋め込み、他の端末に共有可能。サーバーには何も送信されない
- **サークル別管理** — 複数のサークル（部屋）を作成でき、メンバーや設定をサークルごとに別々に保存
- **多言語対応** — 日本語・English・Tiếng Việt を切り替え可能（ブラウザの言語から自動判定。調整さん連携は日本語のみ表示）

- **メンバー管理** — 名前を登録し、当日の参加者をタップで選択（ブラウザに自動保存）。性別（♂/♀）とレベル（上級/中級/初級/初心者）も設定可能
- **調整さん連携** — 調整さんのURLを貼ると、一番◯が多い日程の参加者を自動で参加設定（取り込んだ名前はメンバーとして残る）
- **コート設定** — 予約したコート番号（例: 3,5）を入力すると対戦表に実番号を表示
- **タイムスケジュール** — 開始時刻・所要時間・アップ時間を設定すると、時間割とラウンドごとの時間帯を表示
- **賢いペア編成** — なるべく「同じレベル」かつ「男女MIX」のペアを自動で編成
- **ペア固定 / 毎回シャッフル** — 固定ペアで最後まで戦うか、毎ラウンド組み替えるかを選択（奇数人数は1組だけ3人交代制）
- **公平なローテーション** — 全員の試合数が均等になり、同じ対戦の繰り返しを避けるアルゴリズム

## 使い方

1. メンバーを登録（または調整さんから取り込み）
2. 開始時刻・コート番号・ラウンド数を設定
3. 「組み合わせを作成」を押す

データはすべてブラウザ内（localStorage）に保存され、サーバーには送信されません。
