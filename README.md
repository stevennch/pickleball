# 🏓 ピックルボール 組み合わせメーカー

ピックルボールサークル向けの、ダブルス総当たり組み合わせ生成Webアプリです。

**👉 アプリを開く: https://stevennch.github.io/pickleball/**

## 機能

- **メンバー管理** — 名前を登録し、当日の参加者をタップで選択（ブラウザに自動保存）
- **調整さん連携** — 調整さんのURLを貼ると、一番◯が多い日程の参加者を自動で参加設定
- **コート設定** — 予約したコート番号（例: 3,5）を入力すると対戦表に実番号を表示
- **タイムスケジュール** — 開始時刻から「前半30分アップ＋90分ゲーム」の時間割とラウンドごとの時間帯を表示
- **公平な組み合わせ** — 全員の試合数が均等になり、同じペア・同じ対戦の繰り返しを避けるアルゴリズム

## 使い方

1. メンバーを登録（または調整さんから取り込み）
2. 開始時刻・コート番号・ラウンド数を設定
3. 「組み合わせを作成」を押す

データはすべてブラウザ内（localStorage）に保存され、サーバーには送信されません。
